# MoonPeg

A pure MoonBit peg-solitaire analysis library under active development. The project interprets a finite board as holes with binary occupancy, applies legal jumps, searches under an explicit node budget and independently replays solutions. No game assets or third-party implementations are copied.

Local development: `moon fmt --check`, `moon check --deny-warn`, `moon test`.

The complete implementation plan and supported boundaries are in docs/SCOPE.md. No public repository, CI success, Release or MoonCakes publication is claimed yet.
